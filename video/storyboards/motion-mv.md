# 台本案 — 作品004「MOTION 73」(モーション73種のMV)

状態:**ゲート1(台本案)— 承認済み**(2026-10-10。12章の決定事項を反映)。いまは **ユーザーが Gemini で絵(設定画+10枚)を作るのを待っている**。絵は5枚ずつ数回に分けて届くので、全部そろうまで取り込み以外はしない。
進め方は `CLAUDE.md` の「標準の制作フロー」と「見てほしい人とリールの決まり」、参考の扱いは `toolbox/reference-analysis.md`。

- 参考:ユーザーの演出メモ(技法のみ)。**参考動画のキャラクター・画風・配色・構図はまねない**。参考動画のファイルはリポジトリに入れない(今回は届いていない)
- 作品名(案):**MOTION 73**(仮)/作品フォルダ:Web の図鑑 `works/motion-zukan/`、動画 `videos/motion-mv/`

## 1. 完成イメージ
- **動画(見るだけの作品)**:AI の曲で歌われるアニメーションの技名 73種が、**歌われる瞬間に、その技の動きで巨大な文字として画面に出る**「動きの図鑑」のMV(約 114 秒)。オリジナルキャラクターの絵と、巨大な文字・太い帯・小さな文字の壁を重ねる
- **Web の「モーション図鑑」(本当に使える物・プレゼント)**:73種の技名(英語+日本語)を押すと、その動きが目の前で再生され、何度でも試せるページ
- **見た人が できること(一文)**:**作りたい映像やサイトに合う動き(フェードイン・グリッチ・3Dキューブ など)を、名前と実際の動きで見くらべて選べる。**

## 2. 方針
- **尺:約 114 秒(曲 107.7 秒+締め 6 秒)。** リールは 3分まで投稿できるので、**この作品だけの例外として 90 秒を超えてよい**(ユーザーの指示・2026-10-10)。TikTok・X も同じ尺
- **色は3色だけ**:黒 `#0E0E0E`・オフホワイト `#F2F0E9`(紙のような地の色。ブランドの白 `#FFFFFF` より少しくすませる)・ライム `#C6FF3D`。中間色は黒の不透明度だけ
- **文字**:
  - 主役は **巨大な英語の技名**(歌詞と一字一句同じ。すべて大文字)。画面の端からはみ出すほど大きく、縦長なので **2〜3段に積む/縦に置く** も使う。1語の中で **1文字だけライム** にする
  - **日本語の技名** は英語の近くに小さく添える(英語の文字の高さの **4分の1〜3分の1**)。指定の一覧どおりの表記で、かっこの補足も入れる。**最低 0.7 秒は読める状態で止める**
  - 英語のフォント(案):**Anton**(Google Fonts・無料 OFL・縦長の極太サンセリフ。縦長の画面で大きく積みやすい)。ブランドの Space Grotesk Bold は太さが足りないので、今回はこの作品だけ Anton を提案する(英語の小さな文字の壁・ロゴは Space Grotesk)
  - 日本語のフォント:ブランドの **Zen Kaku Gothic New**(Black 900 を追加。Bold 700 は同梱済み)
- **質感**:オフホワイトの地に紙のざらつきと細かいノイズ。グリッチ(横ずれ)・色ずれは **一瞬だけ**
- **使う道具**:動画は **Remotion**(新しい composition「MotionMV」。文字と動きはすべてコード)。Web の図鑑は **GSAP**(1作品1ライブラリ)。UI は `frontend-design`。費用のかかる生成は使わない
- **プレゼント**:あり/なしは「12. 確認したいこと」で質問(あり の場合のキーワード案は『モーション』、届けるのは Web の「モーション図鑑」)
- 画面の文字は SNS のボタン・説明文に隠れる範囲(上 220px・下 420px・右 160px)に **読ませたい文字(日本語・フック・締め)を置かない**。巨大な英語は はみ出す演出なので範囲にかかってよいが、語の中心は範囲の内側に置いて読めるようにする

## 3. 曲の解析結果
解析は numpy だけで行った(PyPI につながらず librosa などは入れられなかった)。方法:短時間フーリエ変換 → 立ち上がりの強さ → 自己相関でテンポ → 拍の格子の位相を合わせる/調波と打楽器の分離(中央値フィルタ)で声の帯域を調べる/曲に入っていた字幕(4〜5 秒ごとの歌詞の行)で行の順番を確認。

- **テンポ:86.03 BPM**(1拍 0.697 秒。8分音符が強く刻まれていて、体感は倍の 172 BPM)。10 秒以降は拍の格子からのずれが 0.005 秒以内で一定。拍の頭:0.645 秒 + 0.697 秒 × n(小節の頭は −0.052 秒 + 2.790 秒 × n)
- 声が終わるのは約 **107.7 秒**、そのあと無音

- **技名ごとの時刻は推定**(下の 4章の表)。行の区切りを小節に合わせ、行の中の言葉を8分音符の格子に、音節の数に合わせて並べた。**誤差は ±0.5 秒くらいありうる**
- そのため制作の最初に **「時刻合わせ用の確認動画」**(曲の音つき・技名の文字が推定の時刻に出るだけの簡単な動画)を作って送る。聞いてずれている所を教えてもらい(または私が音と見くらべて)、0.1 秒単位で直してから本番の動きを作る

## 5. 全体の雰囲気と音
- **テンポ**:86 BPM の拍(体感 172)に、カットと文字の動きの始まりをそろえる。Verse は拍ごと、ブレイクは2拍ごと、Chorus は「文字だけの速い連打(半拍ごと)」と「文字と絵を大きく見せる止め(2拍)」を交互に
- **色と明るさ**:Intro〜Pre-Chorus はオフホワイトの地(明るい)→ Chorus で黒地に反転(いちばん強い)→ Verse 2 でオフホワイトに戻る → Outro で暗転
- **音**:**曲だけを使う。効果音は足さない**(曲そのものが技名を歌っているので、効果音を重ねると声が聞き取りにくくなる)。曲の音量は −14〜−16 LUFS にそろえる(元の曲の音量を測って決める)。BGM はなし(この曲が音楽)
- **動きの気持ちよさ**:入りは強い減速(終わりで止まる)、消えは加速(始めはゆっくり)、ループは一定。止まる瞬間を拍の頭にそろえる

## 8. コードで表しにくい技と、その代わりの表し方
3色だけ・コードだけ という条件で、そのままでは難しい技は次のように表す。どれも **見た人が技名から想像する動きに近いこと** を優先する。

| 技 | 難しいところ | 代わりの表し方(コードで) |
|---|---|---|
| INK SPLASH | 液体のしぶきの形 | 不規則な円を重ねたしぶきの形(SVG)をライムで一気に広げ、その形を窓にして文字を見せる(マスク) |
| SMOKE DIFFUSION | 煙のゆらぎ | 文字の輪郭にノイズのゆがみ(SVG の turbulence)をかけ、ぼかし+透明化+小さな粒(黒の不透明度)を上へ流す |
| SHATTER | ガラスの割れ | 文字と絵をあらかじめ決めた20個ほどの三角の破片に切り分け、ひびの線(黒の細線)→破片が回りながら落ちる |
| PAPER TEAR | 紙の破れ目 | ギザギザの切り口(clip-path)で画面を上下に引き裂き、切り口にオフホワイトの細い「紙の白」の縁をつける |
| LENS FLASH | 光の玉・虹色 | 虹色は使えないので、ライムの円と細い光の筋(放射状のグラデーション)が横切り、一瞬 画面全体を白飛び(オフホワイト) |
| NEON GLOW | 光のにじみ | 黒の地に ライムの文字+同じ色のぼかしを3段重ねて、ちらつきながら点灯 |
| GRADIENT SHIFT | 多色のグラデーション | 3色の中だけで:黒→ライム→オフホワイト のグラデーションが文字の中を流れる |
| RGB SPLIT | 赤・緑・青のずれ | 3色の中だけで:文字を ライム と 黒 の2枚にずらして重ね、拍ごとに ずれ幅を変える(本来の色ではなく「色ずれの見え方」を再現) |
| MORPHING | 形から形への変化 | 円(コマの目の形)→ 文字の形 へ、SVG の形を補間して変える。文字の形は事前に輪郭データにしておく |
| SEAMLESS ZOOM | 切れ目のないズーム | 「SEAMLESS ZOOM」の「O」の穴へ ズームし続けると、その中から次のセクション(Chorus の黒地)が出てくる |
| MATCH CUT | 形の一致でつなぐ | 文字の「O」→ コマの目の丸(絵4)へ、同じ位置・同じ大きさで切り替える |
| PARALLAX | 奥行き | 小さな文字の壁(奥)・帯(中)・絵(手前)・巨大文字(いちばん手前)を、違う速さで横に流す |
| 3D CUBE / PAGE TURN / FLIP X・Y / 3D TILT | 立体 | CSS の 3D 変形(遠近つき)。面にはそれぞれ文字と絵5を貼る |
| ACCORDION | 蛇腹 | 文字を横に8本の帯に切り、互い違いに折りたたむように縮めて広げる |
| MOSAIC | モザイク | 文字と絵を荒い四角の格子に置き換え(解像度を落として拡大)、拍ごとに細かくして元に戻す |
| DISTORTION WAVE / WAVE / RIPPLE | 波のゆがみ | SVG のゆがみフィルタ(displacement)を時間で動かす。RIPPLE は中心から同心円の輪(細線)も広げる |
| FILM ROLL | フィルムの帯 | 黒い帯の両端に四角い穴(オフホワイト)を並べたフィルムを縦に流し、コマ(絵)を1コマずつ送る |
| SHINE | 光の走り | 文字の上を、斜めの細いオフホワイトの帯が1回だけ横切る(文字の形で切り抜き) |
| MAGNET | 引き寄せ | 画面に散った文字のかけら(1文字ずつ)が、コマの手(絵8の突き出した手のひら)へ吸い寄せられて単語になる |
| HOVER SCALE / TOOLTIP POP | マウスの操作 | 動画には指もマウスもないので、矢印カーソル(黒の図形)を画面に出して文字に重ね、拡大/吹き出しを出す |
| COUNT UP / PROGRESS LINE / CIRCULAR PROGRESS | — | 数字(0→73)・細い線のバー・円のゲージをライムで。どれも2拍で満タンに(待ち時間を見せない) |
| BUBBLE POP | 泡 | 文字のまわりに丸い泡(輪郭の細線)が集まり、拍で1つずつ はじけて文字も消える |

- **グリッチ・色ずれ・点滅(BLINK)は、どれも 0.2 秒以内 の一瞬だけ**。強い点滅が続かないようにする(見ていて つらくならないように)

**案2:3色だけで、虹色をどう出すか**
```
使う色は、黒とオフホワイトとライムの3色だけ、と決めました。
困ったのは「RGBスプリット」や「グラデーションシフト」のような、色そのものが主役の技。
赤も青も使えないので、ライムと黒の2枚をずらして「色がずれて見える感じ」だけを残しました。
制約があると、技の正体が何なのか、考え直すことになります。

I limited myself to three colors: black, off-white, and lime.
The hard part was techniques where color is the whole point, like RGB Split or Gradient Shift.
With no red or blue, I offset a lime layer and a black layer to keep only the feeling of colors slipping apart.
Constraints make you rethink what a technique really is.
```

**案3:曲の拍を、数字で数えた**
```
AIで作った曲に、文字の動きを合わせるために、まず拍を数えました。
音の立ち上がりを調べると、1分間に約86拍。
歌われる技の名前を、その拍の上に並べていくと、どこで何が出るかの地図ができます。
耳で合わせる前に、数字で下書きしておくと、あとの調整がずっと楽になりそうです。

To sync text motion to an AI-made song, I started by counting the beats.
Analyzing where the sounds hit, it came out to about 86 beats per minute.
Laying the sung technique names on that beat grid gives you a map of what appears where.
Drafting with numbers before tuning by ear should make the rest much easier.
```
