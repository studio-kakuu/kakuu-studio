### なしの競技の提案
- **柔道**:コードで作ると、2人の動きを手で作るので時間がかかり、形もぎこちなくなりやすい。**おすすめは案B(外す)。** 代わりに入れるなら、データのある **ボクシング**(13_17・14_01〜14_03・15_13 など。武道の回の「打つ」動き)
- **弓道**:動きが少なく、ほとんどが静止なので、手で作っても品質を保ちやすい。**おすすめは案A(コードで作る)。** 「離れ」の瞬間に粒がはじけると、静けさとの対比で見せ場になる
- **剣道**:代用の振り下ろしで作れるが、本物らしさは一段落ちる。作ってみて弱ければ外す

## 1. シリーズ全体の方針
- **全4話・各話 66 秒(61 秒以上)・縦 1080×1920・30fps。** 各話 3〜4 競技
  - 第1話 球技:バスケ/サッカー/野球
  - 第2話 ネット競技:バレー/テニス/バドミントン
  - 第3話 武道:空手/柔道/剣道/弓道(柔道・弓道は0章の案しだい)
  - 第4話 ストリート&パワー:水泳/ラグビー/スケボー/BMX
  - 4競技の回は、1競技を 14 秒(7小節)に縮めて 66 秒に収める
- **曲**:ユーザーが Gemini で作る(歌なし・120BPM 一定・太鼓とエレクトロのドラム・8小節のくり返し)。届いたら差し替える。映像は最初から **1拍 0.5 秒・1小節 2 秒** に合わせて作り、**力が解放される瞬間は必ず小節の1拍目**
- **コマ**:キューブの粒の集まり(体の粒 2.6cm・頭の粒 1.9cm、約 5,900 粒、ボールは約 370 粒)。設定画どおり、白い枠の角の丸いモニターの頭/黒い画面にライムの丸い目2つ/アンテナ(先にライムの玉)/首に黒いヘッドホン/黒いパーカー(前が開いて内側とファスナーのフチがライム、ライムのひも)/黒い細身のパンツ/黒い靴にライムの線/手はロボット
- **粒の演出**:打つ・蹴る・跳ぶなど力が解放される瞬間に、粒がはじけ飛び、約1秒で体に戻る。解放した手足の近くほど大きく飛ぶ。各競技の最初は、足元から粒が集まって組み上がる
- **背景**:競技ごとに色を変える、くすんだ単色の壁と床。壁は拍で伸び縮みする細い棒の列(イコライザー)、床は拍ごとに足元から広がる同心円の波紋(小節の1拍目は大きく、解放の瞬間はオフホワイトの3重の輪)。ネオンの強い光は使わない。粒の色(黒・白・ライム)で強弱をつける
- **競技ごとの色**(壁/床):バスケ 砂色 `#B3A289`/`#A08F76`、サッカー くすんだ緑 `#8E9A82`/`#7E8A73`、野球 青灰 `#8A97A3`/`#7A8793`、バレー くすんだ水色 `#93A6AE`/`#83969E`、テニス 赤土 `#B08A78`/`#9F7A68`、バドミントン 薄紫灰 `#9D97A8`/`#8D8798`、空手 生成り `#BDB5A1`/`#ADA591`、柔道 藍灰 `#7F8A9A`/`#6F7A8A`、剣道 藍 `#6F7A8C`/`#606B7C`、弓道 木の色 `#A89A84`/`#988A74`、水泳 水色灰 `#87A0A8`/`#779098`、ラグビー 泥の茶 `#8F7F6C`/`#7F6F5C`、スケボー コンクリート `#9A9A96`/`#8A8A86`、BMX 赤さび `#A3806E`/`#93705E`
- **カメラ**:少し下からが基本。力をためる場面で寄り、解放の瞬間に引く。キャラクターの周りをゆっくり回る。解放の瞬間に3コマ(0.1 秒)の止めと、わずかな揺れ
- **文字**:英語は Anton、日本語は Zen Kaku Gothic New Black。左上に「KAKUU GAMES」と話数、右上に「01 / 14」の通し番号、競技名(英語+日本語)、解放の瞬間に技名(英語+日本語)

## 3. 作り方(AI動画は使わない)
1. **動きのデータ**:CMU のモーションキャプチャ(BVH・120fps)から、競技に合うものを選ぶ(0章)。使うファイルだけ `videos/kakuu-games/mocap/` に置く(出典と利用条件は `works/kakuu-games/SOURCES.md`)
2. **拍に合わせる**(`videos/kakuu-games/build_event.py`):
   - どのデータも同じコマの骨の長さで動かす(人ごとの背丈の違いを合わせる)
   - 「出力の秒 → 元のデータの秒」のキーで速さを変える。ドリブルは手が一番低い所を拍に、シュートは頂点を小節の1拍目に置く
   - 同じ秒のキーを2つ置いた所が止め(3コマ)
   - 2つのデータのつなぎ目は、関節の回転を 0.3〜0.4 秒かけて混ぜる。向きと位置は前の続きから始める
   - ボールの位置(ドリブル・持つ・放つ・粒から組み上がる)も同じスクリプトで出す
3. **コマの3Dモデル**(`video/remotion/src/kakuu-games/koma.ts`):骨のまわりに格子状にキューブを置いて作る。1粒ずつ1本の骨にくっつけて、骨の回転で動かす
4. **映像**(`video/remotion/src/kakuu-games/Event.tsx`):Three.js を @remotion/three で Remotion の中に置き、1コマずつ決まった絵を描く。ヘッドレスの Chromium の WebGL(`--gl=angle`)で書き出す

## 7. Threads のつぶやき案3本(公開日に `captions/threads/<公開日>_day<N>.md` に入れる。今日の分は `captions/threads/2026-10-10_day5.md`)

### 案1:本物の動きのデータは、無料で使える
```
キューブの粒でできたキャラを、スポーツで動かしています。
動きは手で付けず、大学が無料で公開しているモーションキャプチャのデータを使っています。
ドリブル、シュート、空手の型まで、2,500本くらいある。
「AIで動画を作る」以外にも、昔からある無料の資料を組み合わせる道があるんだと思いました。

I'm making a character built from tiny cubes play sports.
Instead of animating by hand, I'm using free motion-capture data released by a university.
Dribbles, shots, even karate forms. There are about 2,500 clips.
Besides generating video with AI, combining old free resources is another path.
```

### 案2:拍に合わせるために、動きの速さを変える
```
曲は120BPM。1拍0.5秒に、動きを合わせたい。
でも本物のドリブルは、だいたい0.87秒に1回で、拍に合いません。
そこで、手がいちばん低くなる瞬間を拍に置いて、その間の速さを少しずつ変えました。
シュートの頂点は、小節の1拍目に。人の動きに、あとから拍を通すような作業でした。

The music is 120 BPM, so each beat is half a second.
But a real dribble takes about 0.87 seconds, which doesn't fit.
So I put the lowest point of the hand on each beat and adjusted the speed in between.
The top of each shot lands on the first beat of a bar. It felt like threading a beat through human motion.
```

### 案3:データがない競技を、どうするか
```
14競技のうち、弓道と柔道は、使える動きのデータがありませんでした。
弓道は動きが少ないので、腕の角度をコードで作れそう。
柔道は2人で組む動きなので、1人分のデータでは作れない。
全部そろえるより、データがある所とない所を見極めるのが、最初の仕事でした。

Out of 14 sports, kyudo and judo had no usable motion data.
Kyudo has few movements, so I can probably build the arm angles in code.
Judo needs two people grappling, so one person's data won't work.
Before building anything, the first job was figuring out where the data exists and where it doesn't.
```
