## 2. 方針
- **尺:約 126 秒(曲 120 秒+締め 6 秒)。** この作品だけの例外として 90 秒を超えてよい(ユーザーの指示)。TikTok・X も同じ尺
- **色は3色だけ**:黒 `#0E0E0E`・オフホワイト `#F2F0E9`(この作品だけの例外)・ライム `#C6FF3D`。中間色は黒の不透明度だけ
- **曲調の変わり目で、画面の色と雰囲気を切り替える**(5章)
- **文字**:
  - 主役は **巨大な英語の技名**(歌詞と一字一句同じ。すべて大文字)。画面の端からはみ出すほど大きく、**2〜3段に積む/縦に置く** も使う。1語の中で **1文字だけライム** にする
  - **日本語の技名** は英語の近くに小さく添える(英語の文字の高さの 4分の1〜3分の1)。指定の一覧どおり(かっこの補足も入れる)。**1語あたり約1秒** なので、日本語は英語と同時に出して、次の語まで消さない
  - 英語のフォント:**Anton**(この作品だけの例外)/日本語:**Zen Kaku Gothic New**(Black 900)
- **くり返しはない**(どの技名も1回ずつ)。**同じ絵が2カット続かないように** 絵1〜11 を割り当てる(4章・6章)
- **質感**:オフホワイトの地に紙のざらつきと細かいノイズ。グリッチ・色ずれ・点滅は一瞬だけ
- **使う道具**:動画は **Remotion**(composition「MotionMV」)。Web の図鑑は **GSAP**。UI は `frontend-design`。費用のかかる生成は使わない
- **プレゼント:あり**(キーワード『モーション』、届けるのは Web の「モーション図鑑」の URL)
- 読ませたい文字(日本語・フック・締め)は SNS のボタン・説明文に隠れる範囲(上 220px・下 420px・右 160px)に置かない

## 3. 曲の解析結果(新しい曲)
解析は numpy だけ(PyPI につながらない)。方法:立ち上がりの強さ → 自己相関でテンポ → 6 秒ごとに拍の位置を確認/曲の左右の差から **中央に置かれた声だけ** を取り出し(AI の曲では声が中央にある)、調波の成分の立ち上がりを 1/16 秒単位で見る。

- **テンポ:120.0 BPM**(1拍 0.5 秒)。拍の頭は **0.294 秒 + 0.5 秒 × n**。曲の最初から最後まで、6 秒ごとに確かめても ずれは 0.004 秒以内(一定)
- **声の立ち上がりは 1 秒(2拍)ごと**(0.294 秒 + 1 秒 × n)。作った人の説明(約1秒に1語・1回ずつ)と一致
- 音量:約 −12.4 LUFS(書き出しで −14 にそろえる)。声が終わるのは約 116.5 秒、120.06 秒で曲が終わる

## 8. コードで表しにくい技と、その代わりの表し方
3色だけ・コードだけ という条件で、そのままでは難しい技は次のように表す。**見た人が技名から想像する動きに近いこと** を優先する。

| 技 | 難しいところ | 代わりの表し方(コードで) |
|---|---|---|
| INK SPLASH | 液体のしぶきの形 | 不規則な円を重ねたしぶきの形(SVG)をライムで一気に広げ、その形を窓にして文字を見せる |
| SMOKE DIFFUSION / EVAPORATE | 煙・蒸気のゆらぎ | 文字の輪郭にノイズのゆがみ(SVG の turbulence)をかけ、ぼかし+透明化+小さな粒(黒の不透明度)を上へ流す。EVAPORATE は下から消える |
| SHATTER | ガラスの割れ | 文字と絵をあらかじめ決めた20個ほどの三角の破片に切り分け、ひびの線 → 破片が回りながら落ちる |
| PAPER TEAR | 紙の破れ目 | ギザギザの切り口(clip-path)で画面を上下に引き裂き、切り口にオフホワイトの細い縁 |
| LENS FLASH / LIGHT LEAK | 光・虹色 | 虹色は使えないので、ライムの円と細い光の筋が横切る/画面の端からオフホワイトのにじむ光(放射状のグラデーションを重ねる) |
| NEON GLOW | 光のにじみ | 黒の地に ライムの文字+同じ色のぼかしを3段重ねて、ちらつきながら点灯 |
| GRADIENT SHIFT | 多色のグラデーション | 3色の中だけで:黒→ライム→オフホワイトのグラデーションが文字の中を流れる |
| RGB SPLIT | 赤・緑・青のずれ | 文字を ライムと黒の2枚にずらして重ね、拍ごとにずれ幅を変える(「色ずれの見え方」を再現) |
| MORPHING | 形から形への変化 | 円(コマの目の形)→ 文字の形へ、SVG の形を補間して変える |
| SEAMLESS ZOOM | 切れ目のないズーム | 「SEAMLESS ZOOM」の「O」の穴へズームし続けると、その中から Chorus の画面が出てくる |
| MATCH CUT | 形の一致でつなぐ | 文字の「O」→ コマの目の丸(絵4)へ、同じ位置・同じ大きさで切り替える |
| PARALLAX | 奥行き | 小さな文字の壁(奥)・帯(中)・絵(手前)・巨大文字(いちばん手前)を違う速さで流す |
| 3D CUBE / PAGE TURN / FLIP IN X・Y / FLIP OUT / 3D TILT | 立体 | CSS の 3D 変形(遠近つき)。面に文字と絵を貼る |
| ACCORDION / VENETIAN BLINDS | 蛇腹・板 | 文字を横に8本の帯に切り、互い違いに折りたたむ/1本ずつ回転させて開く |
| MOSAIC / PIXEL IN / PIXEL OUT | モザイク・粒 | 文字と絵を荒い四角の格子に置き換え、拍ごとに細かくして戻す/粒を集める・散らす |
| DISTORTION WAVE / WAVE / RIPPLE / JELLO / WOBBLE | 波・ゆがみ | SVG のゆがみフィルタを時間で動かす/文字のゆがみ(skew)と傾きを減衰する振動で |
| FILM ROLL | フィルムの帯 | 黒い帯の両端に四角い穴を並べたフィルムを縦に流し、絵を1コマずつ送る |
| SHINE | 光の走り | 文字の上を斜めの細いオフホワイトの帯が1回だけ横切る |
| MAGNET / RUBBER BAND | 引き寄せ・引っぱり | 散った文字のかけらがコマの手(絵8)へ吸い寄せられる/手が文字の端を引っぱり、ばねの動きで戻る |
| HOVER SCALE / TOOLTIP POP | マウスの操作 | 動画には指もマウスもないので、矢印カーソル(黒の図形)を画面に出して文字に重ねる |
| COUNT UP / PROGRESS LINE / CIRCULAR PROGRESS | — | 数字(0→100)・細い線のバー・円のゲージをライムで。1拍で満タンに |
| BUBBLE POP | 泡 | 文字のまわりに丸い泡(細い輪郭)が集まり、拍で1つずつはじける |
| KALEIDOSCOPE | 万華鏡 | 文字と絵を三角形で切り抜き、6方向に回して並べ、全体をゆっくり回す |
| CLOCK WIPE / IRIS IN・OUT / WIPE IN・OUT | 形の窓 | 扇形・円・まっすぐな境目の clip-path を時間で動かす |
| ZOOM BLUR | 放射状のぶれ | 同じ文字を少しずつ大きくして薄く8枚重ね、寄りながら1枚にまとめる |
| SCRAMBLE TEXT | 文字のシャッフル | 1文字ずつ、ランダムな英字(固定の乱数で毎回同じ並び)を何回か出してから正しい文字に止める |
| PARTICLE BURST / CONFETTI | 粒・紙吹雪 | あらかじめ決めた位置と速さの粒(丸・四角)をライムと黒で飛ばす・降らせる(毎回同じ動き) |
| REWIND | 巻き戻し | 直前の2秒の動きを逆再生し、テープの早戻しのような横すじを重ねる |
| SQUASH AND STRETCH / ELASTIC IN / BREATHING | 伸び縮み | 縦横の大きさを別々に動かす(つぶれると横に広がる)/行き過ぎて戻るばねの動き/ゆっくりした拡大縮小 |
| ORBIT / MARQUEE | 周回・流れる文字 | 1文字ずつ円周上に置いて回す/帯の中で文字を流し続ける |
