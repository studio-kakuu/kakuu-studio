# 参考動画の取り込みルール(Gemini → Claude Code)

参考にしたい動画(SNSの映像・CM・Webサイトの紹介動画など)があるときの流れ。
目的は **演出の技法を学ぶこと**。そのまま真似した作品は作らない。

## 流れ

1. **Gemini に参考動画を渡す**(あなたが手作業で行う)
   - 動画ファイルをアップロード、またはURLを貼る
   - 下の「分析用プロンプト」をそのまま送る
2. **Gemini が「演出指示書」を返す**
   - 最後の箇条書き(演出指示書)をコピーする
3. **Claude Code に貼る**
   - 例:「次の作品は〇〇(テーマ)。参考の演出指示書はこれ:(貼り付け)」
4. **Claude Code が作る**
   - `CLAUDE.md` のルールどおり、演出指示書は **技法の参考** として使い、作品の世界観に合わせたオリジナルとして作る
   - 何を参考にしたか(カメラワーク・文字の出し方・転換など、技法の名前だけ)を `works/<作品名>/tools.md` に一行記録する

## 守ること

- 参考動画のロゴ・人物・キャラクター・映像素材・音楽・文言・構図をそのまま使わない
- 取り入れるのは「寄りから引きへ」「1文字ずつ出る」「黒幕で転換」のような **技法** だけ。色・形・言葉・題材は作品ごとに新しく決める
- 参考動画のファイル自体はリポジトリに入れない(著作権のある素材は使わないルール)
- 有料APIは使わない(Gemini での分析はあなたのアカウントで手作業で行う。Claude Code から Gemini は呼ばない)

## 分析用プロンプト(Gemini にそのまま送る)

```
この動画を、別のAIが「雰囲気を参考にして、オリジナル作品として再現・アレンジできる」レベルで分析してください。そのまま真似するためではなく、演出の技法を学ぶ目的です。
以下の項目で、日本語で具体的に書き出してください。
1. 全体の印象(どんな雰囲気・テンポ・ジャンルか)
2. タイムライン(何秒〜何秒に何が起きるか、場面ごとに)
3. カメラワーク(寄り・引き・回転・傾きなど、動きの方向と速さ)
4. 文字の出し方(フォントの雰囲気、出現・消え方の演出、位置、大きさ)
5. 場面転換の方法
6. 色使い・光・質感
7. 動きの気持ちよさの理由(加速・減速の付け方、リズム、間)
8. 音と映像の合わせ方(わかる範囲で)
9. この演出の「一番の見どころ」と、それを別のテーマで再現するときのポイント
最後に、上記をまとめて、コードで映像やWebサイトを作るAIへの「演出指示書」として、箇条書きで出力してください。
```

## 演出指示書を受け取った Claude Code の進め方

1. `toolbox/README.md` を読み、演出に合う道具を選ぶ(Webなら GSAP+Lenis、映像なら Remotion など)
2. 演出指示書から「技法」だけを抜き出して短く整理する(例:冒頭2秒で寄り、1文字ずつ、黒幕転換、減速の強いイージング)
3. 作品のテーマ・世界観を先に決め(UIは `frontend-design` に従う)、その上に技法を当てはめる
4. 参考動画と見比べて「同じに見える」部分があれば変える
