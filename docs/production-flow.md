# 制作フロー(全作品)— 詳しい手順

CLAUDE.md の「制作フロー」の詳細。2026-10-11 から、**確認を取るのは費用がかかる生成の直前だけ**。それ以外は止まらずにまとめて進める。

## 流れ
1. `STATUS.md` → `toolbox/README.md` を読み、道具とスキルを選んで `works/<作品名>/tools.md` に記録
2. **台本**を作り `video/storyboards/<作品名>.md` に保存(書式は下)。確認は取らずに次へ
3. **費用がかかる生成の直前だけ止まる**(ナレーション・画像・効果音・音楽など)。出すもの:
   - 生成する内容(ナレーションなら場面ごとの「画面の文字」と「読ませる文」の対照表と、直した箇所と理由)
   - 消費クレジットの目安(文字数 × 本数+リテイク分)
   - OK 後に **1回で** 生成する(ナレーションは `toolbox/narration-rules.md`)
4. **本番**:制作して、下の「完成パッケージ」を1回でまとめて作る
5. `STATUS.md` を更新してコミット・プッシュ

承認済みの台本・投稿文・ナレーションは、断りなく内容を変えない(変えるなら、変えた箇所を示してもう一度 OK をもらう)。

## 台本の書式(`video/storyboards/<作品名>.md`)
画面の文字・ナレーション原稿・テロップ・投稿文は **すべて一字一句書く**(「…」で省略したり「例」と書いたりしない)。
0. **冒頭 1.5 秒の文字(フック)**:「何を、AIで作ったか」を画面の文字で(例:「AIだけで、よみきかせ絵本を1冊つくった」)。見てほしい人(AIで何かを作ることに興味がある人)に刺さる理由を一言。釣りの冒頭(「これ、すごくない?」「最後まで見て」など)は使わない
1. **完成イメージ**:見るだけの作品/触れるデモ/本当に使える物。見た人が何をできるかを一文で
2. **方針**:プレゼントの有無、ねらい、尺(61〜75 秒。読み聞かせの作品は 90 秒まで)
3. **構成**:場面ごとに「秒数/画面に映るもの/画面の文字(全文)/ナレーション原稿(全文。なければ「なし」)/カメラ/テロップ(全文)/効果音」。ナレーションのある場面は、読み終えるのに必要な長さ(前0.5秒+読む時間+後0.8秒前後)にする
4. **雰囲気と効果音**:テンポ・色・音の方向。効果音は1つずつ音色・音量・長さ・鳴らす場所(`scripts/make-sfx.py`)
5. **テロップ一覧**:フック・場面ラベル・右下の表示・締め
6. **締め方**:依頼文で指定がなければ、ユーザーに聞く
   - プレゼントあり:コメントのキーワードで URL やプロンプトを配る(例「コメントで『OS』と送ってね」)。右下に「〇〇のURLは最後に」を出す
   - プレゼントなし:次回予告などで締める。右下の URL 予告は出さない
7. **投稿文**:Instagram / TikTok / X の全文と、Threads のつぶやき案3本(書き方は `brand/brand.md` 7章)
8. **迷っている点**:箇条書きで

## 完成パッケージ(本番の書き出し時に1回でまとめて作る)
- **全媒体の動画**:`videos/<作品名>/instagram.mp4` / `tiktok.mp4` / `x.mp4`(プレゼントありは締めが媒体ごとに違う)。**各 30MB 以内**(超える場合はビットレートを下げて書き出し直す)
- **`captions/<作品名>.md`** に次をまとめる:
  - Instagram / TikTok / X(本投稿+英語リプライ)/ Threads(3案とおすすめ1つ)の投稿文。そのまま貼れる完成形で
  - 媒体ごとの投稿チェック項目(`captions/posting-checklist.md` から、この作品に当てはまるものだけ)
  - プレゼントありの場合:ManyChat の設定(キーワード・公開の返信・DM 文面とボタンのリンク)
- 完了報告:確認に使った静止画(表紙・代表的な場面・締め)を添付し、チェックリストの結果(画面の文字・ナレーション・テロップ・効果音・締め・投稿文が台本と同じか、`video/spec.md` 8章)を付ける。長い文章はチャットに出さず、ファイル名だけ書く

## 有料クレジットを使う生成(ElevenLabs など)
- APIキーは環境変数(例 `ELEVENLABS_API_KEY`)から読むだけ。値を表示・保存・コミットしない
- 生成の前に、クレジット量の目安を示して確認を取る(上の「流れ」3)
- ナレーションは承認済みの原稿どおりに、全体を1回で生成する。生成した音声の文字ごとの時刻で場面の秒数を調整し、場面の切り替えは前の場面の最後の声と次の場面の最初の声の中間(読み終わる前に切り替えない)
- 使った声の名前と ID、seed は `works/<作品名>/tools.md` に記録

## テンポのルール
- 同じような動き(読み込み・カウントアップ・待ち時間など)が続く部分は、早送り(`playbackRate`)・カット・場面転換で数秒にまとめる。早送り中は「×3」などを小さく出す
- 61 秒以上の条件は、削った分を「完成品をじっくり見せる・ビフォーアフター・数字の出どころ」で満たす。待ち時間を伸ばして埋めない
- 早送りした区間の効果音は、間引いて重ならないようにする
