# KAKUU STUDIO

毎回「架空のお店・ブランド」のWebサイトを作り、その制作過程を縦型ショート動画で発信するスタジオ(@studio_kakuu)。
GitHub Pages で公開する静的サイトです。

| パス | 内容 |
|---|---|
| `index.html` / `works.js` | トップページ(作品一覧)。作品追加は `works.js` に1件足すだけ |
| `brand/` | 世界観(色・フォント・ロゴ・`brand.md`) |
| `works/cafe/` | 001 YUGE 湯気と珈琲(架空のカフェ)。`step1/` 構成、`step2/` デザイン、直下が完成版 |
| `captions/cafe/` | Instagram / TikTok / X の投稿本文(日英) |
| `video/` | 動画の設計書 `spec.md` とレンダラー |
