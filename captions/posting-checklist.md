# 投稿チェックリスト(毎回この順で確認)

対象:Instagram / TikTok / X。作品ごとの本文は `captions/<作品名>/`、ルールは `brand/brand.md` 7章と `toolbox/reels-growth.md`(リールの決まり)。
投稿済みの作品(カフェ・KAKUU OS・くものこ もこ)の投稿文は変えない(2026-10-10 の決まりは次の作品から)。

## 投稿前
- [ ] 動画は `videos/<作品名>/<媒体>.mp4`(プレゼントありは媒体ごとに締めが違うので取り違えない)。プレゼントなしの作品は `videos/<作品名>/<作品名>.mp4` を3媒体共通で使う
- [ ] 本文は `captions/<作品名>.md` の同じ媒体の欄からコピー(005 までは `captions/<作品名>/instagram.txt` など)
- [ ] ハッシュタグの数:Instagram **3個まで**(2026-10-10 に5個から変更)/TikTok 5個/X 本投稿・リプライ各2〜3個
- [ ] キャプションの **1行目にテーマとキーワード** がある(例:「AIとコードで、よみきかせ絵本をつくりました」)。本文に共通キーワード(AI、AI制作、つくってみた、架空の世界)と作品ごとのキーワードが自然に入っている。実在の製品名は書いていない
- [ ] 動画の冒頭 1.5 秒に「何を、AIで作ったか」の文字が出ている(`toolbox/reels-growth.md`)
- [ ] 締めの文言が動画と同じ(キーワードも一致)
- [ ] 数字(制作時間など)が `measured_time.txt` などの実測と一致している

## 投稿画面で(全媒体・毎回)
- [ ] **AIラベルをオンにする**
  - Instagram:詳細設定 →「AIラベル」をオン
  - TikTok:その他のオプション →「AI生成コンテンツ」をオン
  - X:AIで作成した旨のラベル・表示がある場合はオン(ない場合は本文の「※AIで制作しています」などの記載で代える)
  - ※各アプリの表示名は変わることがある。見つからないときは「AI」で設定項目を探す
- [ ] **Instagram(リール)だけ**:
  - [ ] 「オーディエンス」で **「メイングリッドとリールグリッドに表示」がオン**
  - [ ] AIラベルがオン(上の項目)
  - [ ] キャプション1行目にキーワードがある/ハッシュタグ 3個以内
- [ ] BGM はここで各アプリの音源から付ける(動画には効果音のみ)。BGM を付けた場合は効果音とぶつからない音量に
- [ ] カバー(サムネイル)は冒頭のフック画面を選ぶ

## ManyChat(プレゼントありの作品:Instagram のコメント → DM で URL を届ける)
画面の名前は変わることがある。見つからないときは「Comments」「Keyword」で探す。

**初回だけ**
- Instagram をプロアカウントにし、設定 →「メッセージとストーリーズへの返信」→「つながったツール」で **メッセージへのアクセスを許可** をオン
- ManyChat に @studio_kakuu をつなぐ

**作品ごとの設定**
1. Automation → New Automation → トリガー **「User comments on your Post or Reel」**
2. 対象の投稿:**投稿前に作るなら「Next Post or Reel」**(次に投稿したリールに自動でつく)/投稿後なら、そのリールを選ぶ
3. **Keywords**:作品のキーワード(例『ゲームズ』)。ゆれも足す(ひらがな・濁点違い・英語。例 `げーむず` `ゲームス` `games`)
4. 公開のコメント返信(任意):2〜3種類をランダムに出す(例「DMでお届けしました!📩」「ありがとうございます!DMを見てみてください」)
5. DM:本文+URL ボタン1つ。文面の型:
   ```
   コメントありがとうございます!
   「<プレゼント名>」はこちらです。
   <何ができるかを一文>
   (個人の資料・作品に使えます。再配布・販売はご遠慮ください)

   Thanks for commenting! Here's the <英語のプレゼント名>.
   ```
   - ボタン名:`ひらく / Open` など/リンク:プレゼントの公開URL(`https://studio-kakuu.github.io/kakuu-studio/works/<作品名>/`)
6. **Set Live** でオン。「フォローしたら届く」の条件は付けない(取りこぼしが減る)

**テスト**
- [ ] 別のアカウントでそのリールにキーワードをコメント → 公開の返信と DM が届くか
- [ ] DM のボタンから URL が開くか(スマホで)
- [ ] キーワードのゆれ(ひらがな・英語)でも届くか
- [ ] 無料プランの上限(連絡先の数など)を ManyChat の料金ページで確認
