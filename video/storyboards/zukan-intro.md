状態:制作済み(2026-10-18)。LP `works/zukan-intro/`、動画 `videos/zukan-intro/instagram.mp4` / `tiktok.mp4` / `x.mp4`(64.0秒・締めだけ違う)。設定は `video/themes/zukan-intro.json`
2026-10-18 変更:最初の版(動画だけ・プレゼントなし・62秒)から、ユーザーの依頼で「LP で、できることを見せて受け取ってもらう」形に作り直した

## 0. 冒頭 1.5 秒の文字(フック)
- 「AIとコードでつくった / プレゼント中の / モーション図鑑の紹介」(「プレゼント中」はアクセント色)。0コマ目から全文(2026-10-18 ユーザーの依頼で変更。「AIでつくった」は冒頭のルールのため残した)
- 刺さる理由:AIで何かを作りたい人が「動きの名前を知るとAIに頼みやすい」と、自分の制作に使える道具として見られる

## 1. 完成イメージ
- 本当に使える物:004 の「モーション図鑑」(`works/motion-zukan/`)と、その LP(`works/zukan-intro/`)。見た人は、図鑑でできること(押すと動く・6グループで探せる・名前でAIに頼める・MVと同じ動き)を知り、コメントで図鑑を受け取れる

## 2. 方針
- プレゼント:**あり**。受け取りは MV「MOTION 100」の投稿へのコメント『モーション』→ 004 の ManyChat の DM で図鑑の URL(新しい自動返信は作らない)
- 投稿時に Instagram の編集で右下に MV を重ねるため、右下は空ける:字幕は画面の上(左上ラベルの下、左寄せ。`notesTop`)、右下の URL 予告は出さない(2026-10-18 変更)
- 尺:64.0 秒。ナレーションなし(有料の生成なし)、効果音のみ
- 素材:LP と図鑑を Playwright で押しながら撮影(`capture.mjs` の `keys` / `clicks`、押した所にライムの丸い波紋)+ MV の 109.4〜113.0 秒(CONFETTI)

## 3. LP の中身(`works/zukan-intro/index.html`、画面の文字は全文そこにある)
1. 冒頭:「無料でお届けする、動きの図鑑」/ 動く見本「MOTION 100」(STAGGER IN → GLITCH IN → BOUNCE → SHATTER → WAVE → CONFETTI をくり返す)/「いまの動き ○○」/「アニメーションの技100種を、名前と動きで見くらべる図鑑。」/ ボタン「受け取り方を見る」
2. 名前を押すと、その動きで動く(BOUNCE を押せる見本)
3. 6つのグループから探せる(グループを押すと代表の動き:ZOOM IN / EVAPORATE / WHIP PAN / JELLO / SHATTER / CONFETTI)
4. 名前がわかると、AIに一言で頼める(「タイトルを BOUNCE / GLITCH IN / TYPEWRITER で出して」を押すと TITLE がその動きで出る)
5. MVと同じ動きで、001から100まで
6. 受け取り方(1 MVの投稿に『モーション』とコメント/2 DMで図鑑のURLが届く/3 名前を押して100種を試す)+「モーション図鑑を開く」リンク
