# 投稿チェックリスト(毎回この順で確認)

対象:Instagram / TikTok / X。作品ごとの本文は `captions/<作品名>/`、ルールは `brand/brand.md` 7章。

## 投稿前
- [ ] 動画は `videos/<作品名>/<媒体>.mp4`(媒体ごとに締めが違うので取り違えない)
- [ ] 本文は同じ媒体のファイルからコピー(`instagram.txt` / `tiktok.txt` / `x.txt`)
- [ ] ハッシュタグの数:Instagram 5個まで/TikTok 5個/X 本投稿・リプライ各2〜3個
- [ ] 締めの文言が動画と同じ(キーワードも一致)
- [ ] 数字(制作時間など)が `measured_time.txt` などの実測と一致している

## 投稿画面で(全媒体・毎回)
- [ ] **AIラベルをオンにする**
  - Instagram:詳細設定 →「AIラベル」をオン
  - TikTok:その他のオプション →「AI生成コンテンツ」をオン
  - X:AIで作成した旨のラベル・表示がある場合はオン(ない場合は本文の「※AIで制作しています」などの記載で代える)
  - ※各アプリの表示名は変わることがある。見つからないときは「AI」で設定項目を探す
- [ ] BGM はここで各アプリの音源から付ける(動画には効果音のみ)。BGM を付けた場合は効果音とぶつからない音量に
- [ ] カバー(サムネイル)は冒頭のフック画面を選ぶ

## 投稿後
- [ ] X:本投稿(日本語)にリプライで英語版を付ける
- [ ] Instagram:コメントにキーワードが来たら URL を届ける(自動返信を使う場合は動作確認)
- [ ] 投稿日と媒体をメモ(次の作品の DAY 表示・集計に使う)
