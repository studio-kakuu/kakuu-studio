# ナレーションのルール(ElevenLabs)

ナレーション付きの作品で声を作るときの決まり。別プロジェクトの教訓をまとめたもの。
クレジットの扱い(キーを表示しない・本番以外は事前に確認する)は `CLAUDE.md` の「有料クレジットを使う生成」に従う。進め方は `CLAUDE.md` の「標準の制作フロー」のゲート2。

## 1. 設定
- モデル:`eleven_multilingual_v2`
- 速さ(speed):**基本 0.8**(2026-10-09 に 0.9 から変更。0.9 は速くて聞き取りにくかった)。緩急をつけたい文だけ変える(例:擬音を軽快に 0.95)
- 生成したら、文ごとの長さを前回・試し録りと比べて、**速さの設定が本当に効いているか確かめる**(0.9 → 0.8 で長さがほぼ変わらなかったことがある)
- stability:**0.9**
- seed:**固定の番号を毎回同じに使う**(作品ごとに `works/<作品名>/tools.md` に番号を記録する)
- 生成は `convert_with_timestamps`(REST では `POST /v1/text-to-speech/{voice_id}/with-timestamps`)を使い、**1文字ずつの時刻** を受け取って保存する

## 2. 生成のしかた(1本で/文ごとに)
- 緩急がいらない作品は、**全体を1回で生成する**(声の大きさ・声色をそろえるため)。場面の区切りはタイムスタンプで決め、Web の絵本の「よみきかせ」ボタン用の音声も、この1本からページごとに切り出す
- **緩急が必要な作品は、文ごとに生成し、前後の文を渡してつながりを保つ**(`previous_text` / `next_text` に前後の読ませる文を入れる)。声・モデル・stability・seed は全文で同じにし、文ごとに変えてよいのは速さだけ。各文のタイムスタンプも受け取り、文字の出方と場面の切り替えに使う。Web の「よみきかせ」ボタンには文ごとのファイルを使う
- 全体を1回で生成したとき、speed 0.9 → 0.8 で長さがほぼ変わらなかった(2026-10-09)。文ごとの生成(ひらがな中心・speed 0.8)に変えると、同じ文の声の長さが約2倍になった(ひらがな化・文ごとの生成・speed が同時に変わったので、どれが効いたかは切り分けていない)
- 間のタグ `<break time="…" />` は **使っても1か所まで**。場面と場面の間は、録音のあとに動画側でとる(文と文の間は **約1.5秒**)

## 3. 「画面の文字」と「読ませる文」を分ける
画面の文字はひらがなのまま。**読ませる文だけ** を直す。
- 助詞の「は」「へ」は、読ませる文では「わ」「え」に書く
- ひらがなが続いて、区切りや読みを誤りそうな所は、読点を足して区切る
- **この声(Shizuka)では、漢字に戻すと読み間違いが増えた**(雲の子→「りゅうのこ」、風→「ふう」、野原→「ようや」、お花→「おはなし」、戻った→「はった」など)。**ひらがな中心が安定**。読ませる文で直すのは「は→わ」「へ→え」、名前のカタカナ、小さい「っ」のカタカナ化、読点だけにする(声を変えたら試し録りで確かめ直す)
- 小さい「っ」が弱くならない書き方にする(例:カタカナにする、伸ばす音を足す)
- 文や間の直後の、出だしの音が欠けないようにする
- ゲート2では「画面の文字」と「読ませる文」を並べた対照表、直した箇所とその理由、消費クレジットの見込みを出して止まる

## 4. 映像との合わせ方
- 場面の切り替えは、**前の場面の最後の声と、次の場面の最初の声の中間** に置く。読み終わる前に場面を変えない
- 画面の文字の「1文字ずつにじみ出る」演出は、できればナレーションのタイムスタンプに合わせ、**読まれるのと同時に文字が出る** ようにする
- **声が終わったあとは、絵が動く見せ場を残す**(風が吹く・雨が降り続く・花が次々ひらく・虹がかかる など)。何も動かない待ち時間は作らない
- 読み聞かせの作品の尺は **75〜90秒** を目安にする(61秒以上は必ず守る)

## 5. 文字の置き場所
- 絵本の文字やテロップは、各 SNS のボタンや説明文に隠れない位置に置く(1080×1920 の目安:上 220px・下 420px・右 160px には大事な文字を置かない)
- 表紙の題字と「AI と コードで つくった えほん」などのフック文字は、**最初のフレームから見える** ようにする

## 6. 音声ファイルの扱い
- 作った音声ファイル(とタイムスタンプの JSON)は作品フォルダに保存して再利用し、**同じ内容で二重に生成しない**
- 使った声の名前・ID・モデル・設定・seed・文字数(消費クレジット)を `works/<作品名>/tools.md` に記録する
