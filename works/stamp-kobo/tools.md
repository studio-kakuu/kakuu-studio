# 009 スタンプ工房 — 紹介ページ

LINE スタンプを半自動で作るツール「スタンプ工房」(本体は別リポジトリ `yuji2110n-web/stamp-kobo`、公開 https://yuji2110n-web.github.io/stamp-kobo/)の紹介と受け取り方のページ。

## 道具
| 用途 | 道具 | メモ |
|---|---|---|
| ページ | 静的 HTML + CSS + 小さな JS(`lp.js`) | 動きのライブラリは使っていない。自動で動くのは冒頭のトークだけ(CSS) |
| スタンプの見本 | `img/st/00〜39.webp` | ツール本体で仕上げた40個を書き出したもの。ねこは動作確認用にコードで描いた絵 |
| 画面写真 | `img/*.webp` | 紹介動画用に Playwright で撮った画面(540×960) |
| フォント | Zen Maru Gothic(ツール本体と同じ)、フォロー案内だけ Space Grotesk | Google Fonts(OFL) |

## スキル
- `frontend-design`

## デザインの考え
- 色はツール本体と同じ(#EDF1F0・#1C2629・スタンプの赤 #D63A5A)と、LINE のトーク画面の青 #8098BB。受け取った先のツールと見た目がつながるように
- いちばん目立たせるのは「できたスタンプ」。冒頭はトークで使った例、次に40個を全部並べる
- 番号は「使う流れ」「受け取り方」の手順だけ
- 受け取り方の一文は、配布の前・最中・後で自動で変わる(日本時間 10/26 21:00〜23:59)
